# SkarletMoon Boutique

Free static website for GitHub Pages.

## Quick start
1. Create a public GitHub repository named `skarletmoon-boutique`.
2. Upload everything in this folder.
3. Go to Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your free website address.

## Customize
Open `index.html` to change the text, email, and social links.
Add more photos to `images/` and add them to the Gallery section.
